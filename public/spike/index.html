Notes it thinks you played

    A run of readings only counts as a note once it has been held for 80ms, so a stray frame or two never becomes one. This is the number that matters: nothing downstream will ever act on a single frame.

    Anything the browser can decode — m4a from a phone, wav, mp3. The whole file is analysed at once and plotted above, which shows far more than the live view can.
